# Screenshot gallery

Every screen in FlowMind, captured from a real running instance with demo data. These images are regenerated by one script, so they stay current:

```bash
# with the app running (API on :8000, UI on :5173), an admin account, and optionally ClickHouse / the vector databases / MLflow up
ADMIN_EMAIL=... ADMIN_PASSWORD=... SHOP_DB=postgresql://user@host/db WAREHOUSE_PG=postgresql://user@host/warehouse_db \
  NODE_PATH=$(npm root -g) node scripts/capture_screenshots.js
```

Images are written to `docs/images/gallery/<area>/`.
