# FlowMind AI — Progress 2026-10-27

## Phase 3 — trust in the data
- **Quality Check node**: 10 rule types (not empty, unique, range, allowed values, regex, max empty %, min/max rows, schema contract, custom SQL condition), must-pass vs warn-only, stop or warn mode, example offending rows (masked), evaluated in one scan inside the sandboxed engine.
- **PII detection on values** (email, phone, Aadhaar/Verhoeff, PAN, card/Luhn, IBAN/mod-97, SSN, IPv4) on top of name-based tagging; **Protect personal data** in Clean (hash/salt, mask, redact, blank).
- **Profiling** (`/data/.../profile`) with suggested checks and plain-language reasons; UI: Profile on Data page, "Suggest checks from my data" in the gate editor.
- **Lineage**: OpenLineage RunEvents (official client classes) per run and per data node, stored + exportable, optional forwarding to a lineage backend; lineage + quality shown in Runs.
- Docs: `docs/phase3-trust-and-lineage.md`, beginner guide extended (quality, protect, profile, lineage, two tutorials), new example file `orders_dirty.csv`, two sample pipelines.
